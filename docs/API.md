# API Reference

Base URL: `http://localhost:3001/v1`  
Auth: `Authorization: Bearer <jwt>` on every request.  
Full OpenAPI spec: `docs/openapi.json` (generated by `pnpm --filter @cs/api build:openapi`)

---

## Error Envelope

All errors use:
```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Human-readable message",
    "requestId": "uuid",
    "details": {}
  }
}
```

---

## Pagination

All list endpoints use **keyset (cursor) pagination**:
```
GET /v1/channels?cursor=<opaque>&limit=50&direction=before
```
Response includes `pageInfo: { hasNextPage, hasPreviousPage, startCursor, endCursor }`.

## WebSocket

Connect: `ws://localhost:3001/v1/ws`

**Protocol:**
1. Client sends `{ "type": "auth", "token": "<jwt>" }`
2. Server responds `{ "type": "auth_ack", "user_id": "...", "company_id": "..." }`
3. Client subscribes: `{ "type": "subscribe", "conversation_id": "...", "cursor": 0 }`
4. Server streams events (see `docs/REALTIME.md`)
5. Heartbeat: client sends `{ "type": "ping" }`, server responds `{ "type": "pong" }`
